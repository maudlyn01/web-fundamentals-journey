JavaScript | Sales Calculator

Construir um script que decide o desconto de cada cliente e processa uma lista de compras.

  1. Criar uma função calcularDesconto(total) que devolve 15% para totais acima de 5 000 MT, 5% acima de 1 000 MT, e 0% abaixo disso.
  2. Usar if / else if / else dentro da função e devolver o valor com return — nunca imprimir lá dentro.
  3. Criar um array com cinco valores de compra e percorrê-lo com um ciclo for…of.
  4. Para cada compra, chamar a função e mostrar na consola o total, o desconto aplicado e o valor final, com template literals.
  5. Acrescentar um contador que soma quantos clientes tiveram desconto e mostrá-lo no fim do ciclo.
