JavaScript | Lesson 3 | Exercises

Analisar os dados de vendas de uma loja moçambicana usando arrays de objectos e métodos modernos.

  1. Criar um array com seis objectos de venda, cada um com produto, quantidade, precoUnitario e cidade.
  2. Usar map para acrescentar a cada venda um campo total (quantidade * precoUnitario), sem alterar o array original.
  3. Usar filter para obter apenas as vendas de Maputo e apenas as vendas acima de 1 000 MT.
  4. Usar reduce para calcular a receita total, e depois a média por venda.
  5. Aplicar destructuring dentro do forEach para imprimir um relatório linha a linha com template literals.
